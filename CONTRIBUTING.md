# Contributing to Protoviz 3D

Thanks for your interest in contributing to **Protoviz 3D** 🚀  
This project focuses on accurate, visual representations of communication protocols.

## 📌 Before You Start

- Please check **Discussions** for ideas and design questions.
- Use **Issues** only for reproducible bugs or concrete feature requests.
- Keep changes small and focused.

## 🧪 Code & Protocol Guidelines

- Protocol behavior must match real specifications (UART, SPI, I²C, etc.).
- Visuals must reflect actual signal timing and states.
- Avoid “magic behavior” that doesn’t exist in real hardware.

## 🛠 Development Setup

```bash
npm install
npm run dev
```

## 🔀 Pull Requests

- Explain what you changed and why
- Include screenshots or GIFs for visual changes
- Link related Discussions or Issues

## 💬 Community

- Questions and Ideas → Discussions
- Bugs → Issues

**Thanks for helping improve Protoviz 3D <3**
